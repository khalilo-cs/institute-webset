1المبادئ

هوية فاخرة هادئة لمتجر ستائر وأقمشة: الليل الدافئ خلفيةً للحظات المهمة، والذهبي لمسةً لا ضجيجًا، والعاجي مساحةً للقراءة.

فخامة هادئة

أسود دافئ وذهبي شمباني وعاجي؛ الذهبي للتأكيد والأزرار الأساسية فقط.

عربي أولًا

كل الصفحات من اليمين إلى اليسار، والعناوين بخط El Messiri المضمّن، والنص بخط الجهاز لسرعة التحميل.

تباين مضمون

كل نص يحقق 4.5:1 على الأقل؛ الذهبي على الفاتح يُكتب بدرجة #76561f.

حركة تخدم المعنى

ظهور ناعم عند التمرير وارتفاع خفيف عند المرور، وتتوقف كلها مع «تقليل الحركة».

2الألوان

متغيرات CSS في :root. تحت كل لون نسبة تباينه مع النص الداكن (--ink) ومع النص العاجي (--ivory).

4الخطوط

العناوين بخط El Messiri (وزنا 600 و700، ملفات woff2 من 12 إلى 15 KB مستضافة في assets/fonts، رخصة SIL OFL 1.1). نص الصفحات بخط الجهاز (system-ui…): جُرّب خط ويب للنص فهبط أداء الجوال من 99 إلى 93، فاستُبعد.

ستائر تكمّل أناقة بيتك.

--display: "Messiri", system-ui, Georgia, serif — 700 للعناوين، 600 للعناوين الفرعية.

من الأقمشة إلى الستائر المفصّلة، اختَر ما يناسب نافذتك وذوقك. تفصيل ستائر، رول، شرائح معدنية وكهربائية في جدة.

--font: system-ui, -apple-system, "Segoe UI", Tahoma, Arial, sans-serif — 15px، ارتفاع السطر 1.7.

تفصيل ستائر حسب المقاس

تُفصَّل الستائر وفق مقاس النافذة والقماش الذي تختاره، ويؤكد المتجر القياسات والتكلفة النهائية معك قبل البدء.

بطاقة المنتج: خلفية --white، نصف قطر 26px (جوال 20px)، حشو 10px، الصورة بنصف قطر 18px ونسبة 1:1.08، الشارة ليلية شفافة بنص شامبانيا، ارتفاع 8px وإطار ذهبي متدرج عند المرور.

بطاقة القسم: ليلية بنصف قطر 26px، صورة مع تدرج داكن من الأسفل، إطار داخلي ذهبي يظهر عند المرور، وتكبير الصورة 1.09 خلال 1.2 ثانية.

بطاقة الخدمة: حد متدرج ذهبي بسمك 1px (padding-box/border-box)، نصف قطر 24px، أيقونة ليلية 42px تميل −8° عند المرور.

كيف أقيس النافذة قبل طلب الستارة؟

قِس عرض النافذة وارتفاعها، ووضّح للمتجر نوع التركيب ومكان المسار الذي تريده.

الحقول: نصف قطر 14px، حد #e0d3bd، وعند التركيز حد ذهبي وهالة 0 0 0 4px rgba(201,164,100,.2).

10الحركة

الحركة تشرح ما يحدث (ظهور، إضافة إلى السلة، تغيّر حالة) ولا تؤخر المستخدم. المحتوى ظاهر كاملًا دون JavaScript، وكل الحركات تتوقف مع «تقليل الحركة».

--ease cubic-bezier(.2,.75,.2,1)

انطلاق سريع وتباطؤ ناعم: الظهور، البطاقات، الصور، الظلال.

--spring cubic-bezier(.34,1.56,.64,1)

ارتداد خفيف يتجاوز الهدف قليلًا: الأزرار، الأيقونات، العدّادات، النوافذ.

الفخامة

قاعدة «تقليل الحركة» (إلزامية)

@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto }
  *, *:before, *:after { transition: none !important; animation: none !important }
}
/* + the storefront script only adds .reveal-on (scroll reveal) when motion is allowed: */
if (!matchMedia('(prefers-reduced-motion: reduce)').matches && 'IntersectionObserver' in window)
  document.documentElement.classList.add('reveal-on')

أي حركة جديدة يجب أن: تعمل بـ transform وopacity فقط، وتنتهي خلال ثانية (عدا الخلفيات البطيئة)، وتتوقف مع هذه القاعدة، ولا تخفي محتوى إذا لم يعمل JavaScript.

11إمكانية الوصول

حلقة التركيز

3px بلون --gold-ink مع إزاحة 3px وهالة عاجية 6px؛ على الداكن بلون --gold-2.

التباين

4.5:1 حدًا أدنى لكل نص. الذهبي #c9a464 والذهبي الداكن #a8803f زخرفة فقط على الخلفيات الفاتحة؛ النص الذهبي #76561f.

اللمس والتنقل

أهداف لمس 44px على الأقل، رابط «تخطي إلى المحتوى»، معالم الصفحة، حبس التركيز داخل النوافذ وإعادته، تسميات لكل حقل، ونص بديل لكل صورة منتج.

الفحص الآلي: tests/a11y_axe.cjs (axe-core، WCAG 2.0/2.1/2.2 A وAA) على شاشات المتجر والإدارة بالجوال والمكتب — آخر نتيجة موثّقة في docs/QUALITY.md: 0 مخالفات.

12الأيقونات

أيقونات خطية مرسومة داخل الشيفرة (SVG) بإطار 24×24، سمك خط 1.6–1.8، نهايات دائرية، بلون النص الحالي (currentColor). لا مكتبة أيقونات خارجية.
