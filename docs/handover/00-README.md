# دليل حزمة التسليم

هذه الحزمة تسلّم لصاحب متجر **الفخامة للأقمشة والستائر** (جدة) كل ما يلزم لامتلاك النظام وتشغيله وصيانته دون الاعتماد على المطوّر: الشيفرة المصدرية، وقاعدة البيانات، والأدلة، والتصميم، وخطوات النشر، وقائمة الحسابات الواجب نقلها، وقائمة التحقق الأمني، ونموذج الترخيص ونطاق العمل.

## النظام في سطور

- **خادم واحد وقاعدة بيانات واحدة:** الموقع الإلكتروني ولوحة الإدارة وتطبيق Android كلها تتصل بالخادم نفسه (`app.py`) وبقاعدة بيانات SQLite واحدة (`store.db`). أي تعديل من لوحة الإدارة يظهر فورًا في الموقع وفي التطبيق.
- **بلا اعتماديات خارجية:** الخادم مكتوب ببايثون القياسية فقط (Python 3.10 أو أحدث)، ولا يستخدم إطار عمل أو مكتبة خارجية أو خدمة مدفوعة.
- **عربي من اليمين إلى اليسار (RTL)** بهوية «ليل وشامبانيا»: أسود دافئ وذهبي وعاجي، وخط العناوين El Messiri مضمّن داخل الموقع.
- **الطلبات تُسجَّل للمراجعة:** لا يوجد دفع إلكتروني. المنتجات بسعر 0 تظهر «السعر حسب الطلب»، ويؤكد المتجر السعر النهائي مع العميل بعد معرفة المقاس والخامة.
- **التطبيق:** تطبيق Android واحد باسم «الفخامة» للعملاء ومدير المتجر (Android 7.0 فأحدث).

1. **صاحب المتجر:** هذا الدليل ← دليل المستخدم ← دليل لوحة الإدارة ← تسليم الحسابات ← قائمة التحقق الأمني ← الترخيص ونطاق العمل.
2. **الجهة التقنية:** التوثيق التقني ← توثيق الواجهة البرمجية ← دليل النشر ← قائمة التحقق الأمني.

## ما لا تحتويه الحزمة عمدًا

- **كلمات المرور والأسرار:** لا توجد في أي ملف من ملفات الحزمة. تُسلَّم كل كلمات المرور عبر **مدير كلمات مرور** (Password manager)، ويغيّرها العميل بنفسه فور استلامها.
- **ملف `.env`:** خاص بمرحلة التصميم على جهاز المطوّر فقط، ولا يدخل Git ولا صورة Docker ولا هذه الحزمة. كلمة المرور المحلية لمرحلة التصميم الموجودة فيه **يجب ألا تُستخدم في بيئة الإنتاج أبدًا**؛ يرفض الخادم أصلًا الإقلاع بإعداد «كلمة المرور القصيرة» إذا كان متاحًا من خارج الجهاز.
- **البيانات الحقيقية للمتجر:** (الطلبات والرسائل والصور المرفوعة) مصدرها الوحيد الخادم الحي: لوحة الإدارة ← «إعدادات المتجر» ← «النسخ الاحتياطي» ← «تنزيل نسخة احتياطية الآن (ZIP)».
- **مفتاح توقيع تطبيق Android:** ينشئه العميل ويحتفظ به بنفسه (انظر دليل النشر).

## ملاحظة التصميم (Figma)

ملف التصميم: https://www.figma.com/design/LurpnArjhAjDr7oTmQKCOa

- **ما يحويه:** متغيرات الألوان والمقاسات (Variables)، و14 نمطًا للنصوص (Text styles)، و5 أنماط للتأثيرات (Effect styles)، والتدرج الذهبي، وصور المتجر.
- **ما لم يكتمل:** المكوّنات (Components) والشاشات (Screens). توقّف بناؤها بسبب حدود خطة **Figma Starter**: حصة استدعاءات MCP، وحد الصفحات الثلاث للملف.
- **المرجع البصري الكامل إذن هو المجلد `04-Design`:** صفحة نظام التصميم (`design-system.html` و`design-system.pdf`) بالقيم الحقيقية من الكود، ولقطات كاملة لكل صفحات المتجر وشاشات الإدارة بعرض 390 و1366 بكسل.
- **لإكمال ملف Figma:** ترقية فريق Figma إلى خطة **Professional** ترفع هذه الحدود وتسمح بإكمال المكوّنات والشاشات في الملف نفسه.

## الحالة عند إعداد الحزمة

| البند | الحالة |
|---|---|
| الموقع ولوحة الإدارة وقاعدة البيانات | مكتملة ومختبَرة آليًا (اختبارات خادم ومتصفح وإمكانية وصول) |
| تطبيق Android | المشروع جاهز ونسخة **تجريبية** فقط (`artifacts/alfakhamah-TEST.apk` داخل الشيفرة)؛ النسخة الإنتاجية تحتاج نطاقًا دائمًا بـ HTTPS ومفتاح توقيع العميل |
| النشر على خادم إنتاجي ونطاق | لم يتم بعد؛ الخطوات كاملة في دليل النشر وتُنفَّذ بحسابات العميل |
| Google Search Console وBusiness Profile وAnalytics | غير مربوطة بعد؛ تُنشأ بحساب Google الخاص بالمتجر (دليل النشر) |
| خيار «بيانات المتجر حقيقية وجاهزة للنشر والفهرسة» | غير مفعّل بعد؛ لذلك يظهر شريط «نسخة تجريبية» ويبقى الموقع محجوبًا عن الفهرسة إلى أن يُفعَّل |
| رقم واتساب | فارغ عمدًا: رقم هاتف المتجر لم يُؤكَّد أنه واتساب، فيظهر في الموقع كرابط اتصال هاتفي فقط |

## إعادة إنشاء الحزمة

من مجلد الشيفرة المصدرية (يتطلب Git وPython وNode مع Playwright):

```bash
python3 tools/make_handover.py                 # الناتج في dist/CLIENT_HANDOVER/
python3 tools/make_handover.py --out /مسار/آخر
```

يشغّل الأمر خادمًا مؤقتًا ببيانات مؤقتة وكلمة مرور عشوائية لا تُحفظ في أي ملف، ثم يحذفه بعد التقاط الشاشات.
