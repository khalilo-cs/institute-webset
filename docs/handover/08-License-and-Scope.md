## 3. نطاق العمل المشمول

| البند | ما يشمله |
|---|---|
| تصميم الواجهات وتجربة المستخدم (UI/UX) | هوية «ليل وشامبانيا»، صفحات المتجر ولوحة الإدارة بالعربية من اليمين إلى اليسار، تصميم متجاوب للجوال والحاسوب، نظام التصميم ولقطات الشاشات في `04-Design` |
| الواجهة الأمامية (Frontend) | الرئيسية، كل المنتجات والبحث، الأقسام وصفحة القسم، صفحة المنتج بمعرض الصور، من نحن، تواصل معنا، الأسئلة الشائعة، صفحة 404، السلة والمفضلة ونموذج الطلب، سياسة الخصوصية والشروط، تطبيق ويب (PWA) |
| الخادم (Backend) | خادم Python، واجهة برمجية عامة وإدارية، لوحة إدارة للمنتجات والصور والأقسام والطلبات والرسائل والإحصاءات والإعدادات، المصادقة والتحقق بخطوتين وسجل التدقيق |
| قاعدة البيانات | مخطط SQLite، ترقية تلقائية للقواعد الأقدم، بيانات البداية (18 موديلًا من صور المتجر)، النسخ الاحتياطي والاستعادة والتصدير |
| ملفات النشر | `Dockerfile` و`docker-compose.yml` و`deploy/Caddyfile` وملفات نسخة العرض على Hugging Face |
| إعداد SSL | HTTPS تلقائي عبر Caddy وLet's Encrypt على خادم العميل، مع تحويل HTTP إلى HTTPS و HSTS |
| SEO الأساسي | العناوين والأوصاف وcanonical وOpen Graph والبيانات المنظمة وخريطة الموقع و`robots.txt`، وإرشادات Search Console وBusiness Profile |
| التحليلات | إحصاءات ذاتية بلا ملفات تعريف ارتباط في لوحة الإدارة، وربط اختياري بـ Google Analytics 4 بموافقة الزائر |
| أدوات الصيانة | النسخ الاحتياطي التلقائي والتنزيل والاستعادة المتحقَّق منها، فحص الصحة `/api/health`، السجلات المنظمة، الاختبارات الآلية والتكامل المستمر |
| تطبيق Android | مشروع التطبيق الواحد للعملاء والمدير، نسخة تجريبية، وسكربت بناء الإصدار الإنتاجي بمفتاح العميل ونطاقه، و[بناء الإصدار الإنتاجي ورفعه على حساب Play Console الخاص بالعميل] |
| التوثيق والتسليم | حزمة التسليم هذه بكل أدلتها |

## 4. خارج النطاق

- **رسوم الاستضافة** (Google Cloud أو غيرها، بما يزيد على الطبقة المجانية)، و**رسوم النطاق** وتجديده.
- **رسوم الأطراف الثالثة:** Google Workspace، رسوم تسجيل Google Play Console، أي رسوم لواجهات Google البرمجية (API) أو خدمات مدفوعة أخرى، خدمات الرسائل أو البريد أو الدفع الإلكتروني.
- **المزايا الجديدة** غير المذكورة في البند 3، ومنها: الدفع الإلكتروني، الشحن والربط مع أنظمة ERP، الإشعارات، تعدد المستخدمين والصلاحيات، تعدد اللغات.
- إنتاج المحتوى (التصوير، كتابة النصوص التسويقية) وإدخال البيانات بما يتجاوز [ ].
- صياغة النصوص القانونية أو مراجعتها، والتسويق والإعلانات.
- الصيانة والدعم بعد فترة الضمان، إلا باتفاق منفصل.

## 6. الملكية الفكرية

- **عند السداد الكامل** تنتقل إلى العميل ملكية الشيفرة المصدرية والتصاميم والتوثيق المنتَجة خصيصًا لهذا المشروع، ويُنقل إليه مستودع GitHub (انظر «تسليم الحسابات»).
- قبل السداد الكامل: [ترخيص استخدام محدود لغرض التجربة والتقييم فقط].
- تبقى المكوّنات والتراخيص الخارجية (البند 7) خاضعة لتراخيصها الأصلية.
- صور الكتالوج وشعار المتجر وبياناته ملك العميل أصلًا.
- يحق للمطوّر الاحتفاظ بنسخة للمرجعية والدعم كما في «تسليم الحسابات»، و[عرض المشروع في معرض أعماله بموافقة العميل].

## 8. حماية البيانات الشخصية

- يخضع النظام لـ **نظام حماية البيانات الشخصية** في المملكة العربية السعودية ولوائحه (الجهة المختصة: الهيئة السعودية للبيانات والذكاء الاصطناعي «سدايا»).
- **العميل هو جهة التحكم** في بيانات عملائه (الطلبات ورسائل التواصل)، و**المطوّر جهة معالجة** حين يصل إليها لأغراض الدعم: يلتزم بالسرية، وبالوصول بالقدر اللازم فقط، وبحذف أي نسخة عند انتهاء الغرض أو بطلب العميل، وبإبلاغ العميل فورًا بأي حادث أمني يعلم به.
- ما يوفره النظام: موافقة صريحة مع وقتها، تقليل البيانات، إحصاءات بلا بيانات شخصية، Analytics اختياري بموافقة الزائر، سياسة خصوصية وشروط.
- **نصوص سياسة الخصوصية والشروط في النظام قوالب عامة** تُراجع مع مختص قانوني وتُعدَّل وفق ممارسات المتجر الفعلية.
- استضافة البيانات خارج المملكة (مثل مناطق Google Cloud المجانية في الولايات المتحدة) تستدعي مراجعة أحكام نقل البيانات خارج المملكة.
